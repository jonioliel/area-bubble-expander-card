# Area Bubble Expander Card

A Home Assistant Lovelace custom card that automatically shows active entities grouped by Area, with expandable Bubble-inspired sections, safe turn-off controls, Hebrew/RTL support, and a visual editor.

Install through HACS as a Lovelace card and add the resource:

```yaml
url: /hacsfiles/area-bubble-expander-card/area-bubble-expander-card.js
type: module
```
